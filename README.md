# Δήλωση timologio — Λήψη εφαρμογής

Εφαρμογή για λογιστικά γραφεία: υποβάλλει στο myAADE τη **Δήλωση Έναρξης Ηλεκτρονικής Έκδοσης Στοιχείων**
με ένδειξη **timologio** για πολλούς πελάτες, έναν-έναν, με έλεγχο ποιοι έχουν ήδη δήλωση, δοκιμαστική λειτουργία
και κρυπτογραφημένη αποθήκευση κωδικών στον υπολογιστή σας.

## Λήψη

Η τρέχουσα έκδοση βρίσκεται πάντα εδώ:
**https://github.com/vaggelispountos-oss/dilosi-timologio-ekdoseis/releases/latest**

Στην ενότητα «Assets» επιλέξτε:
- **Mac:** `Dilosi_timologio_X.Y.Z.dmg` — ανοίξτε το, σύρετε την εφαρμογή στο Applications, την πρώτη φορά δεξί κλικ → Άνοιγμα.
- **Windows:** `Dilosi_timologio_Setup_X.Y.Z.exe` — εκτελέστε το, Επόμενο → Τέλος. Αν το Windows SmartScreen ρωτήσει, «Περισσότερες πληροφορίες → Εκτέλεση ούτως ή άλλως».

Η εφαρμογή ελέγχει μόνη της για νέες εκδόσεις και σας ειδοποιεί με κουμπί «Νέα έκδοση».

## Πρώτη χρήση

1. Ορίστε ένα master password (κρυπτογραφεί τους κωδικούς TAXISnet των πελατών· δεν ανακτάται αν ξεχαστεί).
2. Καταχωρίστε πελάτες, ή εισαγάγετε μαζικά από Excel (υπάρχει υπόδειγμα μέσα στην εφαρμογή).
3. Τρέξτε πρώτα «Μόνο έλεγχος», μετά «Δοκιμαστική» για έναν πελάτη, και τέλος «Πραγματική υποβολή».

Τα δεδομένα μένουν αποκλειστικά στον υπολογιστή σας. Ο χρήστης είναι υπεύθυνος για τους κωδικούς που καταχωρεί
και για κάθε δήλωση που υποβάλλεται (βλ. όρους χρήσης κατά την εγκατάσταση).
